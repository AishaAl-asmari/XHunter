# X Hunter

منصة استخبارات التهديدات اللحظية — نظام يجمع منشورات من X (Twitter) عبر كلمات مفتاحية،
ويستخدم الذكاء الاصطناعي (OpenAI) لتحليل المعنى الحقيقي لكل منشور وتصنيفه حسب مستوى الخطورة
(عالي / متوسط / منخفض) وفئة التهديد، بدلاً من الاعتماد على مطابقة الكلمات فقط.

## المتطلبات

- Python 3.9 أو أحدث
- مفتاح X API (Bearer Token)
- مفتاح OpenAI API

## التثبيت

```bash
pip install -r requirements.txt
```

## إعداد مفاتيح API

المفاتيح لا تُكتب داخل الكود مباشرة لأسباب أمنية، بل تُقرأ من متغيرات البيئة (Environment Variables).

**Windows (PowerShell):**
```powershell
setx X_BEARER_TOKEN "ضع_التوكن_هنا"
setx OPENAI_API_KEY "ضع_مفتاح_OpenAI_هنا"
```
بعد تشغيل هذا الأمر، أعد فتح PowerShell أو VS Code حتى يتم تحميل المتغيرات الجديدة.

**macOS / Linux:**
```bash
export X_BEARER_TOKEN="ضع_التوكن_هنا"
export OPENAI_API_KEY="ضع_مفتاح_OpenAI_هنا"
```

## التشغيل

```bash
python gui_app.py
```

## الملفات

| الملف | الوصف |
|---|---|
| `gui_app.py` | الكود الكامل للنظام (الواجهة، جمع البيانات، التحليل الذكي، التقارير) |
| `keywords.txt` | قائمة الكلمات المفتاحية المستخدمة بالبحث عن المنشورات |
| `logo.png` / `logo.ico` | شعار النظام |

## المزايا

- جمع منشورات لحظي من X API حسب كلمات مفتاحية (عربي وإنجليزي)
- تحليل ذكي بالذكاء الاصطناعي يميز التهديد الحقيقي عن الكلام العاطفي أو الإخباري
- داشبورد لحظي مع رسوم بيانية وتصنيف فئات التهديد
- دعم لغتين (عربي / إنجليزي) قابل للتبديل لحظياً
- إصدار تقرير PDF
- فلتر إضافي لاستخراج المنشورات داخل السعودية فقط
