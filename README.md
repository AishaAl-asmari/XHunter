# 🛡️ X Hunter
### AI-Powered Real-Time Risk Intelligence Platform for Threat Detection on X

---

## 📌 About
X Hunter is a desktop application that helps security analysts monitor threats on X (Twitter) in real time. It combines keyword-based filtering with AI classification to automatically detect and prioritize High, Medium, and Low risk posts — reducing analyst workload by up to 55%.

---

## 🚀 Features
- 🔍 Real-time post collection via X API v2
- 🤖 AI-powered risk classification (High / Medium / Low)
- 🌐 Bilingual support (Arabic & English)
- 📊 Interactive dashboard with live charts
- 🗂️ 6 threat categories (Cybersecurity, Public Safety, Misinformation, and more)
- 📄 PDF report export
- 🌍 Language toggle button (Arabic ↔ English)

---
